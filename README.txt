Império Rações e Pet Shop · prévia do site (CAATI Tech)

Arquivos:
  index.html        o site completo (estilos, fotos, logos e código já estão dentro dele)
  og-imperio.jpg    imagem que aparece quando o link é enviado no WhatsApp
  imperio-icone.png ícone usado quando o site é salvo na tela do celular

Publicar: envie a pasta inteira (os 3 arquivos juntos) para o GitHub ou para a Vercel.
Depois de publicar, troque no index.html
  <meta property="og:image" content="og-imperio.jpg">
pelo endereço completo, por exemplo:
  <meta property="og:image" content="https://SEU-ENDERECO.vercel.app/og-imperio.jpg">
para a prévia do link aparecer no WhatsApp.
